\section*{Introduction}
\addcontentsline{toc}{section}{Introduction}
\begin{justify}
    Ce projet se concentre sur le développement d'une application mobile innovate qui permet de calculer l'IMG d'une personne fournissant une interface conviviale, réalisée avec Android Studio en utilisant le langage de programmation Java. \\
    Cette application a été conçue dans le but de pratiquer le développement mobile sur la platforme Android.
\end{justify}

\subsection*{Objectifs}
\addcontentsline{toc}{subsection}{Objectifs}
\begin{itemize}
    \item Construction des interfaces.
    \item Codage en Java sous Android suivant le MVC.
    \item Réalisation des tests unitaires.
    \item Génération automatique de la documentation avec JavaDoc.
    \item Codage des actions événementielles.
    \item Exploit des ressources et des objets graphiques dans le code.
    \item Construction d'une application mobile Android simple et fonctionel.
\end{itemize}

\section*{2. Codage en Java sous Android suivant le MVC}
\addcontentsline{toc}{section}{2. Codage en Java sous Android suivant le MVC}
\begin{justify}
    Tout d'abord, pour suivre les normes de l'architecture MVC, on crée 3 packages; controleur, modele et vue. Puis on transfère le fichier \textbf{MainActivity.java} dans le package vue car il est le responsable à l'affichage de l'application. Maintenant on peut commencer le codage du partie modèle.
\end{justify}

\subsection*{2.1 Codage de la partie Modèle}
\addcontentsline{toc}{subsection}{2.1 Codage de la partie Modèle}
\begin{justify}
    Dans cette partie, il faut créer la classe Java \textbf{Profil} qui est la classe contenant les attributs du profil, afin de calculer l'IMG et d'afficher l'image qui lui correspond.
\end{justify}
\begin{lstlisting}
    public class Profil {
    ... // Déclaration des constantes et des attributs de la classe. 
    public Profil(Integer poids, Integer taille, Integer age, Integer sexe) {
        this.sexe = sexe;
        this.age = age;
        this.taille = taille;
        this.poids = poids;
        this.calculIMG();
        this.resultIMG();
    }
    ... // Getters et Setters.
    private void calculIMG() {
        float tailleM = ((float)taille) / 100;
        this.img = (float) ((1.2 * poids / (tailleM * tailleM)) + (0.23 * age) - (10.83 * sexe) - 5.4);
    }

    private void resultIMG() {
        Integer min;

\subsection*{2.2 Codage de la partie Controleur}
\addcontentsline{toc}{subsection}{2.2 Codage de la partie Controleur}
\begin{justify}
    Dans cette section, on doit créer la classe Java \textbf{Controle} sous le package \textbf{Controleur}. Cette classe joue un rôle central dans notre application en gérant l'interaction entre l'interface utilisateur et la logique métier en suivant le modèle \textbf{Singleton}. Elle a d'objectif d'assurer que les données du profil sont correctement créées et accessibles à partir d'autres parties de l'application.
\end{justify}
\begin{lstlisting}
    public final class Controle {
        private static Controle instance = null;
        private Profil profil;
    
        private Controle() {
            super();
        }

        public static final Controle getInstance() {
            if (Controle.instance == null) {
                Controle.instance = new Controle();
            }
            return Controle.instance;
        }
        
        public void creerProfil(Integer poids, Integer taille, Integer age, Integer sexe) {
            profil = new Profil(poids, taille, age, sexe);
        }
    
        public float getImg() {
            return profil.getImg();
        }
    
        public String getMessage() {
            return profil.getMessage();
        }
    }
\end{lstlisting}

\subsection*{2.3 Codage de la partie Vue}
\addcontentsline{toc}{subsection}{2.3 Codage de la partie Vue}
\begin{justify}
    Dans cette section, on doit coder la classe Java \textbf{MainActivity} pour gérer les actions événmentielles de l'utilisateur.
    \begin{itemize}
        \item Au début, on doit réécrire la méthode \textbf{onCreate()} qui est la responsable d'afficher l'interface lors du lancement
        \item puis, pour afficher l'interface \textbf{activity\_main.xml} dans l'écran, on doit utiliser la méthode \textbf{setContentView(R.layout.activity\_main);}
        \begin{lstlisting}
            protected void onCreate(Bundle savedInstanceState) {
                super.onCreate(savedInstanceState);
                EdgeToEdge.enable(this);
                setContentView(R.layout.activity_main);
                init();
                this.controle = Controle.getInstance();
                ecouteCalcul();
                ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
                    Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
                    v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
                    return insets;
                });
            }
        \end{lstlisting}
        
        \item Maintenant, il faut initialiser les champs à manipuler par relier les variables Java avec les objets graphiques créés.
        \begin{lstlisting}
            // Propriétés
            private EditText txtPoids;
            private EditText txtTaille;
            private EditText txtAge;
            private RadioButton rdHomme;
            private TextView lblIMG;
            private ImageView imgSmiley;
            private Controle controle;
        
            private void init() {
                txtPoids = (EditText) findViewById(R.id.txtPoids);
                txtTaille = (EditText) findViewById(R.id.txtTaille);
                txtAge = (EditText) findViewById(R.id.txtAge);
                rdHomme = (RadioButton) findViewById(R.id.rdHomme);
                lblIMG = (TextView) findViewById(R.id.lblIMG);
                imgSmiley = (ImageView) findViewById(R.id.imgSmiley);
            }
        \end{lstlisting}

        \item En fin, pour afficher le résultat aprés le clic sur le bouton calculer, il faut écrire un code qui représente un listener (un écouteur) qui écoute les événements de cliques sur le bouton et qui éxecute la méthode \textbf{afficheResult()}.
        \begin{lstlisting}
            private void ecouteCalcul() {
                ((Button) findViewById(R.id.btnCalc)).setOnClickListener(new Button.OnClickListener() {
                    @Override
                    public void onClick(View v) {
                        // Toast.makeText(MainActivity.this, "test", Toast.LENGTH_SHORT).show();
                        // Log.d("message", "clic sur le btn *************");
                        Integer poids=0;
                        Integer taille=0;
                        Integer age=0;
                        Integer sexe=0;
                        try {
                            poids = Integer.parseInt(txtPoids.getText().toString());
                            taille = Integer.parseInt(txtTaille.getText().toString());
                            age = Integer.parseInt(txtAge.getText().toString());
                        } catch (Exception e) {};
                        if (rdHomme.isChecked()) {
                            sexe = 1;
                        }
                        //contrôle des données saisies
                        if (poids == 0 || taille == 0 || age == 0) {
                            Toast.makeText(MainActivity.this, "Saisie incorrecte", Toast.LENGTH_SHORT).show();
                        } else {
                            afficheResult(poids, taille, age, sexe);
                        }
                    }
                });
            }
        
            private void afficheResult(Integer poids, Integer taille, Integer age, Integer sexe) {
                // Création du profil et récupération des infos
                this.controle.creerProfil(poids, taille, age, sexe);
                float img = this.controle.getImg();
                String message = this.controle.getMessage();
        
                // affichage
                if (message == "normal") {
                    imgSmiley.setImageResource(R.drawable.normal);
                    lblIMG.setTextColor(Color.GREEN);
                } else {
                    lblIMG.setTextColor(Color.RED);
                    if (message == "trop faible") {
                        imgSmiley.setImageResource(R.drawable.skinny);
                    } else {
                        imgSmiley.setImageResource(R.drawable.fat);
                    }
                }
                lblIMG.setText(String.format("%.01f", img) + " : IMG " + message);
            }
        \end{lstlisting}
    \end{itemize}
\end{justify}

\subsection*{3.2 Codage de la classe ProfilTest}
\addcontentsline{toc}{subsection}{3.2 Codage de la classe ProfilTest}
\begin{justify}
    Afin de tester les méthodes de la classe Profil, on doit initialiser des variables conçues par les tests comme le profil à tester, son résultat et image attendues. Puis en utilisant les méthodes prédifinies et les annotations du Framework, on peut les tester correctement". \\
    \hspace{1em}\textbf{@Test}: annotation pour dire que la méthode ci-dessous est un test unitaire. \\
    \hspace{1em}\textbf{assertEquals}: méthode prédifinie pour comparer le résultat attendue avec le résultat actuel retourné par la méthode de la classe Profil.
\end{justify}
\begin{lstlisting}
    public class ProfilTest {
    // Création du profil avec ses résultats correctes 
    private Profil profil = new Profil(67, 165, 35, 0);
    private float img = (float) 32.2;
    private String message = "trop élevé";

    @Test
    public void getImg() {
        assertEquals(img, profil.getImg(), (float) 0.1);
    }

    @Test
    public void getMessage() {
        assertEquals(message, profil.getMessage());
    }
\end{lstlisting}
